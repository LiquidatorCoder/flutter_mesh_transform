# flutter_mesh_transform — example

A runnable demo app that wraps a sample widget in [`MeshTransform`](../lib/flutter_mesh_transform.dart) and exposes interactive sliders for every parameter (`xSpread`, `yFalloff`, `yTravel`, `response`, `dampingRatio`, `maxBlur`).

## Run

```bash
cd example
flutter pub get
flutter run
```

Tested on Android and iOS.
